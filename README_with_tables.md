# Through-Wall Imaging (TWI) Data Collection

## Overview

This repository contains datasets for **Multiple Target Detection using
Through-Wall Imaging (TWI)**.\
Data collected on 03-06-2023 using a 2-port Anritsu VNA and a Vivaldi
antenna.

------------------------------------------------------------------------

## Experimental Setup

  Parameter                  Value
  -------------------------- --------------
  Frequency Range            1.5--3.5 GHz
  Antenna-to-Wall Distance   \~50 cm
  Scanner Height             \~70 cm
  Metal Sheet Size           30×30 cm²
  Wooden Cart Size           40×40 cm²
  Total Scans                28
